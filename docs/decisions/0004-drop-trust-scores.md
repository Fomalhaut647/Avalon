# 0004 删除信任值字段

- 状态：已采纳
- 日期：2026-09-13

## 背景

最初的需求文档要求每名玩家维护对其他每名玩家的数值信任值，区间 [-100, 100] 或 [0, 100]，写在身份文件里。但文档没有设计任何更新它的机制，也没有说明它如何影响决策。

## 决定

删除信任值字段。玩家对他人的判断以自由文本写在每次行动的私下分析里，不做结构化。

## 后果

- 少一个无人维护、会与实际判断脱节的字段。
- 日后若要做定量分析，比如"玩家对 Merlin 的怀疑度随任务的变化"，需要从私下分析文本中事后抽取，而非直接读字段。

## 备选方案

- 保留字段并要求玩家每次行动都输出更新后的信任值。被否决，v1 不需要，且会占用输出篇幅、诱导模型把判断压成数字。
