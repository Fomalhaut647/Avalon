# 0005 v1 五个座位统一使用 DeepSeek V4.1 Flash

- 状态：已采纳
- 日期：2026-09-13

## 背景

.env 中已备有多家提供商的 key。五个座位可以用同一模型，也可以混用不同模型。

## 决定

v1 五个座位统一使用 DeepSeek V4.1 Flash，通过其 OpenAI 兼容接口接入。配置结构上保留"座位到模型"的映射表，只是 v1 五项填同一个值。

## 后果

- 变量最少，先把流程与提示词调通。
- 同模型、同提示词可能导致打法同质化，比如好人全员无脑赞成。这是已知风险，v1 观察而不处理。
- 日后做模型对比只需改映射表，不动代码。

## 备选方案

- 五个座位混用不同模型。搁置到 v1 跑通之后。
