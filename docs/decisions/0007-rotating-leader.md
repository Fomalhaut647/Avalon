# 0007 队长按座位顺时针轮转

> 起草日期：2026-09-14

- 状态：已采纳
- 日期：2026-09-14

## 背景

v1 最初规定每次任务开始时随机指定队长，任务内否决后才顺延。实跑 7 局后发现随机抽签常出现同一人连任：种子 1 的对局里 P4 连续四次任务开局都是队长，种子 42 里 P2 连续三次。抽签本身经两万个种子检验是均匀独立的，问题在于随机指定这条规则本身允许连任，而连任让讨论的主导权长期集中在一个座位上。

本条只替换 [0002](0002-fixed-order-speaking.md) 决定段里"每次任务开始时随机指定队长"一句，0002 的其余内容不受影响。

## 决定

- 队长按座位顺时针轮转。一局的第一任队长随机指定，此后每次提案结束，无论通过还是否决，都换给下一位。
- 一次任务的首任队长就是上一次任务最后一位队长的下一位，与阿瓦隆原版一致。

## 后果

- 每个座位担任队长的机会均等，五次提案内每人恰好一次。
- 随机种子只影响角色分配和第一任队长，开局随机性减少。
- rules.md 第十二节的差异表少了一行，规则更贴近原版。

## 备选方案

- **保持随机指定，但禁止与上一任务首任队长相同**：解决连任，但仍不均等，且是原版没有的规则。
- **保持随机指定**：最简单，但连任体验差。
