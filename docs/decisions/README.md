# 决策记录（ADR）

一个决策一个文件，四位数字编号，文件名英文小写加连字符。

约定：

- 每条记录含"状态、日期、背景、决定、后果"，半页为宜。
- **写完不改。** 改主意时新写一条，把旧记录的状态改为"已被 000X 取代"，其余内容保持原样。
- 只记录"有备选方案、选了其中一个"的决定。没有争议的实现细节不写。
- 状态取值：提议中、已采纳、已被取代、已废弃。
