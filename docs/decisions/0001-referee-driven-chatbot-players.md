# 0001 玩家是 chatbot，一切调度由裁判决定

- 状态：已采纳
- 日期：2026-09-13

## 背景

最初的需求文档把玩家设想为自主 agent：自己读文件、自己决定调用哪个工具、裁判负责校验非法调用并阻止越权读取他人的私有文件。这带来一整套校验逻辑，且玩家一旦有了工具，行为空间就难以约束。

## 决定

玩家只是 chatbot。轮到某个玩家时，裁判把它该看的全部上下文整理好、连同一个明确的问题一起通过 API 发过去，玩家回一段结构化文本。玩家不调用任何工具，不读写任何文件，不知道文件系统的存在。什么时候该谁做什么、答案是否合法、公开部分发给谁，全部由非 AI 的裁判状态机决定。

## 后果

- 非法调用、越权读取两类问题在结构上消失，裁判只需校验答案内容。
- 玩家与裁判之间只有一个接缝 `Player.act(notice) -> reply`。换模型、换提供商、让人类坐进一个座位，都只是换一个 `Player` 实现。
- 状态机可以用随机答题的假玩家完整测试，不联网、不花钱。
- 代价：玩家失去"主动"的能力，比如想插话时不能插话。这在 v1 的固定顺序发言下不是问题。

## 备选方案

- 玩家为工具调用 agent。被否决，理由如上。
