# 0006 默认关闭模型的隐藏思考

> 起草日期：2026-09-14

- 状态：已采纳
- 日期：2026-09-14

## 背景

DeepSeek 接口上的 Flash 模型默认开启隐藏思考：模型先生成一段不返回给调用方的推理，再给出正式回复。首次实跑测得一次发言约 7000 个输出 token、近 40 秒，按一局约 130 次调用估算，一局要一个多小时、近百万输出 token。

[0003](0003-single-thread-memory.md) 已经决定玩家的跨轮记忆只靠可见的私下分析：隐藏思考不会带回下一次请求，对记忆没有贡献，只影响当次回复的质量。

## 决定

- 每次请求显式带上隐藏思考的开关，默认关闭。
- 开关通过 `.env` 中的 `DEEPSEEK_THINKING` 控制，`on` 即开启，方便对比两种模式的对局质量。
- 系统提示词继续要求模型把推理写进私下分析，这一段就是模型唯一的"思考空间"。

## 后果

- 一局的时长与费用下降数倍。
- 模型在每次行动前只有一段可见分析可用，行棋质量可能低于开启隐藏思考时。是否值得为质量付出时长与费用，留待对比几局后再定；若开启更好，改默认值即可，不需要改代码结构。

## 备选方案

- **保持接口默认，开启隐藏思考**：质量可能更高，但一局一个多小时，迭代提示词的周期太长。
- **开启并限制思考长度**：接口暂不提供思考长度参数。
